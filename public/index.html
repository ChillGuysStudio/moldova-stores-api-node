Moldova Stores Product API

Date despre produse din magazine online din Moldova, cu raspunsuri normalizate pentru cautare, fetch dupa URL si fetch dupa ID.

Deschide documentatia Verifica starea API

Puncte rapide

  • GET /stores pentru magazinele disponibile si capabilitatile lor.
  • GET /products/search?q=iphone&page=1&page_size=5 pentru cautare normalizata.
  • GET /products/by-url?url=... pentru produs direct dupa URL.
  • GET /products/{store}/{sourceId} pentru fetch dupa magazin si ID.

Magazine

Bomba, Darwin, Enter, Maximum, Smart si XStore.
